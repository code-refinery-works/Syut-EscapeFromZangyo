# 『シュッ！ (Syut!)』 - Escape from Zangyo Platform

> **「空気を読むな、定時を読め。」**
> 現代の全ビジネスパーソンに捧ぐ、次世代型・超自然体退社支援プラットフォーム。

---

## 🌟 概要

『シュッ！ (Syut!)』は、高度なアルゴリズムと心理戦を用いて、ユーザーの社会的信用をミリも損なうことなく、**物理的・精神的に職場から消滅（定時退社）させること**を唯一の目的としたエンタープライズ偽装型Webアプリケーションです。

「特にやることないのに帰りづらい」「有給申請理由に30分悩む」――そんなオフィス空間の【空気の重力】を無力化し、すべての労働者を平和なアフター5へと導きます。

---

## 🚀 主要機能

- **【F-01】角が立たない『AI言い訳錬金術』**
  - 上司の機嫌（激怒／普通／虚無）と自身の残存HPから、誰も引き留められない完璧な退社口実（家庭円満モード・異次元モード等）をミリ秒で生成。
- **【F-02】緊急ステルス迷彩（パニック・エクセル）**
  - 上司の接近を察知してスペースキーを2回連打すると、0.05秒で「超絶複雑な関数の巨大スプレッドシート（ダミー）」へ緊急退避。打鍵音と深刻な舌打ちのSE演出付き。
- **【F-03】バーチャル残業感・醸成システム（アリバイ工作）**
  - 「朝4:12」の予約投稿や、椅子の背もたれにカーディガンをAR投影する「トイレ行っただけ偽装」で、周囲の心証を完璧にコントロール。
- **【F-04】脱出ルート最適化ナビゲーション**
  - オフィス内の「捕獲リスク（話しかけてくる先輩・急な仕事を振る上司）」をレーダー探知し、死角を通る最短脱出ルートをリアルタイム描画。

## 🛡️ 非機能要件・セキュリティ

- **定時ダッシュ速度**: 18:00:00 の退勤打刻ラグは 0.1 秒以内。
- **エンタープライズ迷彩UI**: SalesforceやSAPに酷似した業務基幹システム風デザイン。
- **社長検知＆履歴完全抹消**: 生体反応検知で日経電子版へ強制リダイレクト、ログアウト時は「最初から有給だった」かのように痕跡消去。
